# Support de WhatsReminder

Ce dépôt public recueille les retours concernant l'extension WhatsReminder : bugs, questions et suggestions d'amélioration.

Le code source de l'extension est conservé dans un dépôt privé distinct. L'ouverture d'un ticket ici ne donne aucun accès à ce code.

## Avant de créer un ticket

- Choisir le formulaire correspondant à votre retour.
- Créer un seul sujet par ticket.
- Masquer les noms, numéros de téléphone, photos, contenus et horaires précis des messages WhatsApp dans toute capture d'écran ou tout extrait partagé.

Merci de contribuer à améliorer WhatsReminder.
